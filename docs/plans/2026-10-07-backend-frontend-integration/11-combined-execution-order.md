## Milestone definitions

**Storage/API foundation:** B1–B4 and F1. It can register/read targets and record supervised jobs; it cannot claim a saved capability until B6.

**Core automation:** B5–B7 and F2. Genuine discovery publication requires B8 evidence; scripted tests only establish mechanics.

**Integrated phase:** F3–F5 + D1. Real lifecycle/replay/evidence integrated with existing Lovable presentation. Handoff/guardrails remain deferred core requirements and are not gates for this pass.

## Inputs still supplied at execution (not ambiguous architecture)

- Actual backend HTTPS origin and browser CORS origin(s); local exported UI origin for local demo.
- User-provisioned MinIO bucket/endpoints/credentials and `/app/data` Railway persistent volume if/when deployment is separately authorized.
- Configured OpenRouter model/key and permitted synthetic fixture URL; no paid run initiated during planning.
- Final compatible Python/new PNG dependency pins, selected at installation; existing Node lock remains otherwise preserved.
- Calibration/performance evidence for recommended visual matcher0.95 threshold; failure of fixture gate blocks visual publication, not permission to use recorded coordinates.

No unresolved semantic decision is delegated to Python: LLM proposes meaning, backend validates contract and execution. Optional future admin mutations/cross-deployment provisioning/remote console are not hidden follow-on stages.
